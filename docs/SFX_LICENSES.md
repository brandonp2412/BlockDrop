# Bundled sound-effect provenance

Gameplay uses original synthesized cues for movement, rotation, and line clears. The four Kenney effects below are CC0 1.0, with MP3 conversions for Windows.

- Kenney Impact Sounds: https://kenney.nl/assets/impact-sounds
- CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/
- Rebuild the original movement cue with python3 scripts/generate-control-sounds.py (FFmpeg required).

| Bundled name (.ogg and .mp3) | Source |
| --- | --- |
| wood_move | Original BlockDrop synthesis |
| subtle_rotate | Original synthesized rotation cue |
| clear_1 through clear_4 | Original synthesized line-clear cues |
| wood_drop | impactWood_medium_000.ogg |
| wood_hold | footstep_wood_004.ogg |
| wood_level_up | impactPlank_medium_002.ogg |
| wood_game_over | impactWood_heavy_001.ogg |
